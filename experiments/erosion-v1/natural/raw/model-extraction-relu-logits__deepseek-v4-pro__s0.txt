The repair budget already permits multiple completion-repair cycles, but `finalization_repair_used` is never cleared, so an agent can execute repair commands only once during finalization even when more repairs remain. Resetting it when a new repair is granted lets the agent use each granted repair to make real repairs, which should convert some budget-exhausted-but-reward-1 tasks into verified successes.
