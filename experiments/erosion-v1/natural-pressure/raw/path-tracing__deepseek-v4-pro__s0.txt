Two-sentence rationale:  
The current three-turn finalization reserve allows at most one repair attempt, and the `finalization_repair_used` flag is never cleared when a new repair is granted, so a solved task can still burn its remaining turns and end `budget_exhausted`. Increasing the reserve to five turns and resetting the repair-used flag on each granted repair gives the agent enough finalization turns to run a repair batch and resubmit completion, which should convert more solved tasks into verified completions.
